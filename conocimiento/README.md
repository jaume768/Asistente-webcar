# Base de conocimiento del asistente

Cada fichero `.md` de esta carpeta es material de ayuda que la herramienta
`buscar_ayuda` puede citar. Se trocea por encabezados `##`/`###`, así que cada
sección debe entenderse sola.

- `webcar-lite-basico.md`: resumen operativo (incluido).
- `guia-webcar-lite.md`: la guía completa para empleados. Exportarla desde el
  documento «Guía Webcar Lite para empleados» (menú del documento → exportar a
  Markdown) y guardarla aquí con ese nombre.
- Añadir aquí: control de versiones de Webcar, guía de implantación, FAQ propias.
